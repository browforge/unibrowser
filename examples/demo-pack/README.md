# Demo content pack

Small files for the [10-minute blitz demo](../docs/blitz-status.md#demo-script-10-min). Open the folder in Unibrowser (omnibox path or Files tab).

| File | Try |
| --- | --- |
| `sample.md` | Markdown preview, font size commands |
| `sample.txt` | Monaco text editor |
| `sample.svg` | SVG viewer |
| `sample.png` | Image viewer, eyedropper stub |
| `sample.unibrow/` | Board/timeline project (`project.json` format v2) |

From the repo root:

```bash
# Example absolute path after clone
cd examples/demo-pack
```

Then in Unibrowser: open this directory as a folder tab and click each sample.
